# Student Placement Management System

A full-stack web application for managing students, companies, jobs, and placement applications.

## Technologies Used

- Java 21
- Spring Boot
- Spring Data JPA
- MySQL
- HTML
- CSS
- JavaScript
- Maven
- Git & GitHub

## Features

- Student Management
- Company Management
- Job Management
- Application Management
- CRUD Operations
- MySQL Database Integration
- REST APIs

## Backend APIs

- `/api/students`
- `/api/companies`
- `/api/jobs`
- `/api/applications`

## How to Run

```powershell
.\mvnw.cmd spring-boot:run
